# Identification of the Inverted Pendulum Model

## Model Description

The dynamics of the system can be described by the equation:

    I * θ'' = -m * g * l * θ + u

where:

- **θ** - pendulum deviation angle,  
- **θ'** - angular velocity,  
- **θ''** - angular acceleration,  
- **I** - moment of inertia,  
- **m** - mass of the pendulum,  
- **g** - gravitational acceleration,  
- **l** - distance from the pivot to the center of mass,  
- **u** - torque generated by the motor.  

## Equation Transformation

To simplify parameter estimation, we define two unknowns:

    α = (m * g * l) / I
    β = 1 / I

Substituting these, we obtain:

    θ'' = -α * θ + β * u

which allows for linear identification of parameters **α** and **β**.  

## State-Space Representation

In state-space form, the model can be written as:

    [ θ'  ]   = [  0    1 ] [ θ  ] + [  0  ] * u
    [ θ'' ]     [ -α    0 ] [ θ' ]   [  β  ]

## Parameter Identification

To estimate **α** and **β**, we can use a linear regression method:

1. **Measurements:**
   - Angle **θ**
   - Angular velocity **θ'**
   - Torque **u**
   - Time samples **t**

2. **Numerical differentiation to compute angular acceleration:**

        θ''_i = (θ'_i - θ'_(i-1)) / Δt

3. **Constructing the regression matrix:**

        [ -θ_1   u_1 ] [ α ]   = [ θ''_1 ]
        [ -θ_2   u_2 ] [ β ]     [ θ''_2 ]
        [  ...    ... ]         [   ...  ]
        [ -θ_n   u_n ]         [ θ''_n ]

4. **Solving the equation using least squares regression, e.g., in Python:**

## Summary

- The model describes the dynamics of an inverted pendulum.
- Parameters **α** and **β** can be estimated using linear regression.
- Knowing **α** and **β** allows for further control system design.



## Transfer Function

Once the parameters `α` and `β` are identified, we can get the transfer function of the system, where the input is the torque `u`, and the output is the angle `θ`.



We derive the transfer function step by step:

1. **Starting from the motion equation:**

   ```
   θ'' = -α * θ + β * u
   ```

2. **Taking the Laplace transform** (assuming zero initial conditions):

   ```
   s²Θ(s) = -αΘ(s) + βU(s)
   ```

3. **Rearrange the equation:**

   ```
   (s² + α)Θ(s) = βU(s)
   ```

4. **Express the transfer function as the ratio of output to input:**

   ```
   G(s) = Θ(s) / U(s) = β / (s² + α)
   ```
